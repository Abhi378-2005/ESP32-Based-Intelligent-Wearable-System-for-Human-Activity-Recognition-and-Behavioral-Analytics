# ⚡ SpineSync AI — PostureGuard™ Pro Analytics & HAR Suite (USB + Bluetooth Edition)

An interactive **Human Activity Recognition (HAR)**, **3D Posture Telemetry**, and **Gamified Behavioral Wellness** web application built for the **ESP32 + MPU6050 Custom Single-Sided PCB Wearable**.

---

## 🌟 Connectivity Options (USB + Wireless Bluetooth Only)
1. **🚀 Interactive Simulator (Demo):** Run live demonstrations of all 6 activities (`Sitting`, `Desk Reach`, `Slouching`, `Walking`, `Running`, `Fall / Impact`) without hardware connected.
2. **🔌 Live USB Serial Cable (`115200 baud`):** Direct plug-and-play streaming over USB.
3. **🔵 Wireless Bluetooth SPP (`PostureGuard_Pro`):** Pair your Windows laptop with `PostureGuard_Pro` via Bluetooth and connect to its assigned Virtual COM Port for completely untethered wearable tracking.

---

## 🚀 Quick Start (Antigravity / VS Code)
1. Unzip `PostureGuard_Analytics_Suite_v3.zip` and open the folder in **Antigravity** or **VS Code**.
2. Install dependencies: `pip install -r requirements.txt`
3. Launch dashboard: `python -m streamlit run app.py` (or double-click `run_app.bat`)
